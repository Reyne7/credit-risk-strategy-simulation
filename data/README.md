# 数据

本项目使用 Kaggle 公开数据集 **Give Me Some Credit** 的训练集 `cs-training.csv`（150,000 行）。

按 Kaggle 竞赛数据的使用规则，原始数据不随仓库分发，请自行下载：

1. 打开 https://www.kaggle.com/c/GiveMeSomeCredit/data
2. 下载 `cs-training.csv`，放到本目录：`data/cs-training.csv`

下载后可核对：150,000 行；`SeriousDlqin2yrs` 均值约 0.0668；`MonthlyIncome` 缺失 29,731 条。
